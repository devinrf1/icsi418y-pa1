My Task List by Devin Finn

My Task List allows user to create a list of tasks with each task having its own priority (low, medium, or high). 
Once tasks are added to the list they can be marked as completed, or remarked as incomplete.
Tasks may also be deleted from the list.

To run, download repository, open project folder, and run index.html in a web browser. 
Type name of task into field, select priority with drop down menu, and add task with button.
Complete/delete items with buttons. 

Currently no know issues.
